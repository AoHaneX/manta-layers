Polices livrées avec l'application (TTF, OTF ou TTC), chargées au démarrage. Ce dossier est facultatif.

Le menu Fichier > Importer une police copie les polices dans le dossier de l'utilisateur
(%LOCALAPPDATA%\MantaLayers\fonts sous Windows, ~/.local/share/MantaLayers/fonts ailleurs),
pour fonctionner même si l'application est installée dans un dossier en lecture seule.
